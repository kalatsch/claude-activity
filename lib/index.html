AI Code Activity

What this shows

Active time is the sum of gaps between consecutive JSONL log events from Claude Code (~/.claude/projects) and Codex CLI (~/.codex/sessions), bucketed by hour × day. Local time.

Snapshot

This page is a static snapshot. For fresh data, re-run /activity in Claude Code — your history is preserved across runs.

Settings

  • gap_minutes10
    longest pause still counted as continuous work.
  • work_intervals[[9, 18]]
    working hours; inside = work (green), outside = off‑hours (yellow). Use two ranges to carve out lunch.
  • work_days[0–4]
    work weekdays (0=Mon … 6=Sun); any day not listed renders as weekend (red).
  • first_day_of_week0
    column order of the “by day of week” chart only (0=Mon, 6=Sun).

Edit ~/.claude-activity/config.json and re-run /activity, or run /activity --settings for the setup wizard.
