claude-activity

A local heatmap of your Claude Code and Codex CLI usage — when you actually worked, by hour × day, with token totals and estimated API cost. Everything runs on your machine; no server, no telemetry.

Claude Code Codex CLI work / off / weekend split daily tokens & API cost persistent history
Install
1

Via the marketplace

Recommended

Two commands inside Claude Code. Updates later with /plugin update.

/plugin marketplace add kalatsch/claude-activity /plugin install claude-activity@claude-activity
2

Manual / dev symlink

Clone and symlink into the plugin cache — handy while hacking on it.

git clone https://github.com/kalatsch/claude-activity.git # symlink it where Claude Code looks for local plugins ln -s "$(pwd)/claude-activity" \ ~/.claude/plugins/cache/local/claude-activity/1
3

Standalone (no plugin)

Just want the dashboard? Run the generator directly with Python 3.

git clone https://github.com/kalatsch/claude-activity.git cd claude-activity python3 lib/generate.py # writes ~/.claude-activity/index.html python3 lib/generate.py --open # …and opens it
After install

Usage

  • /activity — generate & open
  • /activity --settings — work days, hours, gap…
  • /activity --help — all flags
  • /activity --no-open — silent run

Requirements

  • Python 3.9+ — no external packages
  • A modern browser (opens from file://)
  • Reads ~/.claude/projects & ~/.codex/sessions
  • Writes only to ~/.claude-activity
